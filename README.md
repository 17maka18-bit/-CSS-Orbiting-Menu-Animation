# CSS Orbiting Menu

## პროექტის აღწერა

CSS Orbiting Menu არის HTML-ისა და CSS-ის გამოყენებით შექმნილი ანიმაციური მენიუ.

პროექტში რვა აიქონი განლაგებულია ცენტრალური ავატარის გარშემო და მოძრაობს წრიულ ორბიტაზე.

პროექტი შესრულებულია JavaScript-ის გარეშე.

## გამოყენებული ტექნოლოგიები

- HTML5 — გვერდის სტრუქტურის შესაქმნელად.
- CSS3 — დიზაინისა და ანიმაციების შესაქმნელად.
- CSS Grid — ელემენტების განლაგებისთვის.
- CSS Variables — ზომების, კუთხეებისა და მოძრაობის პარამეტრებისთვის.
- CSS Keyframes — ორბიტალური მოძრაობისა და პულსაციისთვის.
- SVG — აიქონების გამოსახვისთვის.

## პროექტის ფუნქციები

1. **Orbit Animation** — რვა აიქონი მოძრაობს ცენტრალური ავატარის გარშემო.
2. **Counter-rotation** — აიქონები მოძრაობის დროს სწორ ორიენტაციას ინარჩუნებს.
3. **Hover Pause** — აიქონზე მაუსის მიტანისას მისი მოძრაობა ჩერდება.
4. **Tooltip** — აიქონზე მაუსის მიტანისას ჩნდება შესაბამისი დასახელება.
5. **Orbit Expansion** — ცენტრალურ ავატარზე მაუსის მიტანისას ორბიტის რადიუსი იზრდება.
6. **Pulse Animation** — ცენტრალურ ავატარს აქვს პულსაციის ეფექტი.
7. **Responsive Design** — მცირე ეკრანებისთვის გამოყენებულია CSS Media Query.

## პროექტის სტრუქტურა

```text
animation/
├── index.html
├── style.css
├── README.md
├── demo/
│   ├── index.html
│   └── style.css
└── assets/
    └── orbit-mechanics.svg
```

- `index.html` — პროექტის ძირითადი HTML.
- `style.css` — ძირითადი CSS სტილები და ანიმაციები.
- `demo/` — მასწავლებლის საწყისი დემონსტრაცია.
- `assets/` — პროექტის დამატებითი ვიზუალური რესურსები.
